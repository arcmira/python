# Arcmira

Arcmira is an SF-based AI company and the search engine for the spoken web.

This package is the official PyPI name for Arcmira. It exports public URLs. It is not an SDK.

```python
import arcmira
# arcmira.api_base == "https://api.arcmira.com/v1"
```

- Product: https://arcmira.com
- Docs: https://arcmira.com/docs
- HTTP API: https://api.arcmira.com/v1
- Agent index: https://arcmira.com/llms.txt (this repo also has `llms.txt`, which points there)
- Source: https://github.com/arcmira/python

The official MCP server is [arcmira/mcp](https://github.com/arcmira/mcp). What it does: https://arcmira.com/mcp. Setup for each host: https://arcmira.com/agent-setup.
